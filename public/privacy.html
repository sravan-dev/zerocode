Privacy Policy

Last updated: 26 September 2026

ZeroCode is an AI model gateway and chat interface operated at zerocode.hellosravan.in. It forwards your chat requests to AI model providers that the operator has connected. This policy explains what data ZeroCode handles and why.

Data we handle

  • Chat messages. Your messages are sent to the AI provider selected for each request so it can generate a reply. ZeroCode does not store message content on the server. Your chat history is saved only in your own browser's local storage.
  • Request logs. For each request the server keeps basic details: time, model used, token counts, response time and any error. It keeps only the most recent 500 entries, in memory, and clears them on restart. Message content is not logged.
  • Google account data. If the operator connects a Google account through “Sign in with Google”, ZeroCode receives the account's email address and OAuth tokens. They are stored on the ZeroCode server and used only to call Google's model API for requests routed to it.
  • Provider API keys and settings. Keys for connected AI providers are stored in the server's configuration so ZeroCode can call those providers.

Google user data

ZeroCode requests the openid, email and https://www.googleapis.com/auth/cloud-platform scopes. It uses them only to identify the connected account and to send model requests to Google's Code Assist API on that account's behalf. ZeroCode does not sell Google user data, use it for advertising, or share it with anyone else, except as needed to send your requests to Google.

ZeroCode's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Third-party AI providers

Requests are processed by the AI providers the operator has connected, such as Google, Groq or OpenRouter. Each provider handles your data under its own privacy policy.

Cookies and tracking

ZeroCode uses no advertising or analytics cookies. Your browser's local storage keeps your chats, settings and theme on your device.

Retention and deletion

Chats stay in your browser until you delete them or clear your browser's site data. Google tokens are deleted when the operator chooses “Remove connector”. You can also revoke ZeroCode's access at any time at myaccount.google.com/permissions.

Security

Traffic to ZeroCode is encrypted with HTTPS. The API and dashboard are protected by an access key. Stored credentials are kept in files readable only by the ZeroCode service.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
